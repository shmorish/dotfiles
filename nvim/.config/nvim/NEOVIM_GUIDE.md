# Neovim 入門ガイド（LazyVim 構成）

この設定は [LazyVim](https://www.lazyvim.org/) をベースにしています。
**キーバインドは LazyVim 標準**なので、ネットの LazyVim 情報がそのまま通用します。

- 公式キーマップ一覧: <https://www.lazyvim.org/keymaps>
- 迷ったら **`Space` を押して 1 秒待つ** → which-key が候補を出してくれる
- キー検索: `Space s k`（全キーマップをあいまい検索）

---

## 0. 最初の 30 秒

| やりたいこと                 | キー                            |
| ---------------------------- | ------------------------------- |
| ファイルを開く               | `Space Space`（ファイル名検索） |
| 文字列で全文検索             | `Space /`                       |
| 保存                         | `Ctrl-s`（または `:w` + Enter） |
| 元に戻す / やり直す          | `u` / `Ctrl-r`                  |
| 終了                         | `Space q q`                     |
| Insert（文字入力）に入る     | `i`                             |
| Insert から抜ける            | `Esc` または `jj`               |
| **とにかく分からなくなった** | `Esc` を 2 回押す               |

> 保存せずに強制終了したいときは `:q!` + Enter。

## 1. モードという考え方

Vim は「今どのモードか」で同じキーの意味が変わります。ここだけ乗り越えれば後は楽です。

| モード       | 入り方           | 何をするところ                                             |
| ------------ | ---------------- | ---------------------------------------------------------- |
| **Normal**   | `Esc` / `jj`     | 移動・削除・コピーなど「操作」をする。**基本はここにいる** |
| **Insert**   | `i` `a` `o` など | 文字を打つ                                                 |
| **Visual**   | `v` `V` `Ctrl-v` | 範囲選択する                                               |
| **Command**  | `:`              | `:w` `:q` などコマンドを打つ                               |
| **Terminal** | `Ctrl-/`         | 内蔵ターミナル（`Esc Esc` で Normal に戻る）               |

Insert に入るキーの違い:

| キー      | 動作                          |
| --------- | ----------------------------- |
| `i`       | カーソルの**前**から入力      |
| `a`       | カーソルの**後**から入力      |
| `I` / `A` | 行頭 / 行末から入力           |
| `o` / `O` | 下 / 上に新しい行を作って入力 |

## 2. 移動

### 基本（Normal モード）

| キー                | 動き                         |
| ------------------- | ---------------------------- |
| `h` `j` `k` `l`     | 左 下 上 右                  |
| `w` / `b`           | 次 / 前の単語の先頭          |
| `e`                 | 単語の末尾                   |
| `0` / `^` / `$`     | 行頭 / 行の最初の文字 / 行末 |
| `gg` / `G`          | ファイル先頭 / 末尾          |
| `{` / `}`           | 段落単位で上 / 下            |
| `Ctrl-u` / `Ctrl-d` | 半画面 上 / 下               |
| `%`                 | 対応する括弧へジャンプ       |
| `42G` または `:42`  | 42 行目へ                    |

数字を前置すると回数になります（`5j` = 5 行下、`3w` = 3 単語進む）。

### 画面内を一気に飛ぶ（flash.nvim / hop.nvim）

| キー              | 動き                                               |
| ----------------- | -------------------------------------------------- |
| `s` + 2文字       | 画面内のその 2 文字へジャンプ（flash）             |
| `S`               | 構文ブロック単位で選んでジャンプ（flash）          |
| `f` / `F` + 1文字 | 画面内のその文字へ（hop。カーソルより前方 / 後方） |
| `t` / `T` + 1文字 | 画面内のその文字の手前へ（hop。前方 / 後方）       |

hop は候補が複数あるとラベル（`etovxqpdygfblzhckisuran` の文字）を表示するので、**目的の文字 →
ラベル文字**の順に押します。飛べるのは画面に表示されている範囲までで、スクロールの外へは飛べません
（そこへ行きたいときは `/` 検索か `Space s b` の行検索を使います）。

`f` `t` は hop に置き換えているため、素の Vim と違い **`;` `,` での繰り返しは効きません**。
flash 側の f/t 拡張は二重になるので切ってあります。

### 検索

| キー            | 動き                              |
| --------------- | --------------------------------- |
| `/文字列` Enter | 前方検索（`n` 次、`N` 前）        |
| `?文字列` Enter | 後方検索                          |
| `*` / `#`       | カーソル下の単語を前方 / 後方検索 |
| `Esc Esc`       | 検索ハイライトを消す              |

### 戻る・進む

| キー                | 動き                       |
| ------------------- | -------------------------- |
| `Ctrl-o` / `Ctrl-i` | ジャンプ履歴を 戻る / 進む |
| ` ` ``              | 直前の位置へ               |

## 3. 編集：「動詞 + 範囲」で覚える

Vim の編集は **動詞（operator）+ 範囲（motion / text object）** の組み合わせです。

**動詞**: `d`削除 / `c`削除して入力 / `y`コピー / `v`選択 / `>` `<`インデント / `gc`コメント

**範囲**: `w`単語 / `$`行末まで / `ap`段落 / `i(`括弧の中 / `a"`引用符ごと / `it`タグの中

| 例                | 意味                                             |
| ----------------- | ------------------------------------------------ |
| `dw`              | 単語を削除                                       |
| `d$` または `D`   | 行末まで削除                                     |
| `dd`              | 1 行削除（`3dd` で 3 行）                        |
| `ciw`             | カーソル下の単語を消して入力開始（**多用する**） |
| `ci(`             | 括弧の中身を消して入力開始                       |
| `ca"`             | 引用符ごと消して入力開始                         |
| `yy` / `yiw`      | 1 行コピー / 単語コピー                          |
| `p` / `P`         | 下（後ろ）に貼り付け / 上（前）に貼り付け        |
| `x` / `r文字`     | 1 文字削除 / 1 文字置換                          |
| `gcc` / `gc`+範囲 | 行コメント切替 / 範囲コメント切替                |
| `u` / `Ctrl-r`    | undo / redo                                      |
| `.`               | **直前の編集を繰り返す**（強力）                 |

### 囲む・置換（mini.surround）

| キー                | 動作                                     |
| ------------------- | ---------------------------------------- |
| `gsa` + 範囲 + 記号 | 囲む（例: `gsaiw"` で単語を `"` で囲む） |
| `gsd` + 記号        | 囲みを削除（例: `gsd"`）                 |
| `gsr` + 旧 + 新     | 囲みを置換（例: `gsr"'`）                |

### ファイル横断の置換

| キー          | 動作                                        |
| ------------- | ------------------------------------------- |
| `Space s r`   | grug-far（プロジェクト全体の検索・置換 UI） |
| `:%s/旧/新/g` | 今のファイルを一括置換                      |

## 4. LazyVim のキー体系（Leader = `Space`）

`Space` を押して待てば which-key がメニューを出します。**丸暗記は不要**で、頭文字だけ覚えれば辿れます。
表示ラベルは日本語化してあります（対訳表は `lua/plugins/which-key.lua`。未登録のものは英語のまま出ます）。

| プレフィックス | 分類                               |
| -------------- | ---------------------------------- |
| `Space f`      | **f**ile（ファイル操作・ファイラ） |
| `Space s`      | **s**earch（検索全般）             |
| `Space b`      | **b**uffer（開いているファイル）   |
| `Space c`      | **c**ode（LSP・リネーム・整形）    |
| `Space g`      | **g**it                            |
| `Space x`      | 診断・quickfix（Trouble）          |
| `Space u`      | **u**i トグル（表示切替）          |
| `Space q`      | 終了・セッション                   |
| `Space w`      | **w**indow（画面分割）             |

### ファイル・検索

| キー                         | 動作                                               |
| ---------------------------- | -------------------------------------------------- |
| `Space Space`                | ファイル名で検索して開く（プロジェクトルート基準） |
| `Space /` または `Space s g` | プロジェクト全文 grep                              |
| `Space ,`                    | 開いているバッファ一覧                             |
| `Space f r`                  | 最近開いたファイル                                 |
| `Space f e`                  | ファイラを開閉（snacks explorer）                  |
| `Space f c`                  | この Neovim 設定ファイルを開く                     |
| `Space s w`                  | カーソル下の単語をプロジェクト検索                 |
| `Space s b`                  | 今のファイル内を行検索                             |
| `Space s k`                  | **キーマップ検索**（困ったらこれ）                 |
| `Space s h`                  | ヘルプ検索                                         |
| `Space s R`                  | 直前の検索結果をもう一度開く                       |

ピッカー内では `Ctrl-j` / `Ctrl-k`（または `↑↓`）で移動、`Enter` で開く、`Ctrl-v` / `Ctrl-s` で縦 / 横分割、`Esc` で閉じる。

### ファイラ（`Space f e`）内の操作

| キー                  | 動作                                                |
| --------------------- | --------------------------------------------------- |
| `Enter` / `l`         | 開く / 展開                                         |
| `a`                   | 新規作成（末尾を `/` にするとディレクトリ）         |
| `r` / `d` / `c` / `m` | リネーム / 削除 / コピー / 移動                     |
| `.`                   | そのディレクトリをルートにする（潜る）              |
| `<BS>`                | 親ディレクトリへ戻る（開いたときのルートまで）      |
| `H`                   | ドットファイルの表示切替（既定は表示）              |
| `I`                   | `.gitignore` されたファイルの表示切替（既定は表示） |
| `Esc` / `Space f e`   | 閉じる                                              |

### バッファとウィンドウ

| キー                   | 動作                                |
| ---------------------- | ----------------------------------- |
| `Shift-h` / `Shift-l`  | 前 / 次のバッファ（上部タブの移動） |
| `Space b d`            | バッファを閉じる                    |
| `Space -` / `Space \|` | 上下 / 左右に分割                   |
| `Ctrl-h/j/k/l`         | 分割ウィンドウ間の移動              |
| `Space w d`            | 今のウィンドウを閉じる              |
| `Space w m`            | 今のウィンドウを最大化（トグル）    |

### コード（LSP）

| キー        | 動作                                   |
| ----------- | -------------------------------------- |
| `K`         | ドキュメントをホバー表示               |
| `gd` / `gr` | 定義へジャンプ / 参照一覧              |
| `gI` / `gy` | 実装へ / 型定義へ                      |
| `Ctrl-o`    | ジャンプ元に戻る                       |
| `Space c r` | リネーム（プロジェクト全体）           |
| `Space c a` | コードアクション（クイックフィックス） |
| `Space c f` | フォーマット（保存時にも自動実行）     |
| `Space c s` | シンボル一覧（アウトライン）           |
| `]d` / `[d` | 次 / 前の診断（エラー・警告）          |
| `Space c d` | その行の診断を表示                     |
| `Space x x` | 診断一覧（Trouble）                    |

### Git

| キー                          | 動作                                                      |
| ----------------------------- | --------------------------------------------------------- |
| `Space g g`                   | **lazygit を開く**（TUI で add / commit / push まで完結） |
| `Space g s`                   | git status のファイル一覧                                 |
| `Space g b`                   | その行の blame                                            |
| `Space g f`                   | このファイルのコミット履歴                                |
| `Space g B`                   | GitHub 上の該当行をブラウザで開く                         |
| `]h` / `[h`                   | 次 / 前の変更箇所（hunk）                                 |
| `Space g h s` / `Space g h r` | hunk を stage / 取り消し                                  |

### ターミナル

| キー      | 動作                                           |
| --------- | ---------------------------------------------- |
| `Ctrl-/`  | 内蔵ターミナルを開閉                           |
| `Esc Esc` | ターミナル内で Normal モードへ（スクロール可） |

### 表示トグル（`Space u`）

`Space u` の後: `w`折り返し / `l`行番号 / `L`相対行番号 / `d`診断表示 / `f`自動整形 / `h`インレイヒント / `z`Zen モード / `C`カラースキーム変更

## 5. 補完

- 入力中に候補が出る（blink.cmp）。`Ctrl-n` / `Ctrl-p` または `↑` `↓` で選択、`Enter` で確定、`Ctrl-e` で閉じる。
- 補完元は LSP・バッファ・パス・スニペット。`Tab` はスニペットのプレースホルダ移動に使います。
- AI 補完は入れていません（必要になったら `:LazyExtras` で `ai.copilot` などを有効化）。

## 6. この設定のファイル構成

```text
nvim/.config/nvim/
├── init.lua                    # 入口（config.lazy を呼ぶだけ）
├── lazyvim.json                # 有効にしている extras（:LazyExtras で編集）
├── lazy-lock.json              # プラグインのバージョン固定（git 管理する）
└── lua/
    ├── config/
    │   ├── lazy.lua            # lazy.nvim のブートストラップ
    │   ├── options.lua         # LazyVim デフォルトへの差分オプション
    │   ├── keymaps.lua         # 追加キーマップ（jj / :W など）
    │   └── autocmds.lua        # 追加 autocmd
    └── plugins/
        ├── claudecode.lua      # Claude Code 連携（ファイラからの追加キー補完）
        ├── colorscheme.lua     # kanagawa-dragon（暗めの不透明背景）
        ├── explorer.lua        # ファイラで隠しファイルも全部表示
        ├── hop.lua             # f/t/F/T を hop の画面内ジャンプに置換
        ├── which-key.lua       # which-key のラベルを日本語化
        ├── autosave.lua        # 自動保存（auto-save.nvim）
        ├── lsp.lua             # Mason で管理する LSP サーバーの宣言
        ├── lualine.lua         # モード表示を色付きの記号に
        └── markdown.lua        # markdown の lint を無効化（整形は prettier）
```

### 独自に足しているもの（LazyVim 標準からの差分）

| キー / 設定          | 内容                                                                                                                                     |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| `jj`                 | Insert モードを抜ける（旧設定から引き継ぎ）                                                                                              |
| `:W` `:Q` `:WQ` など | Shift 押しっぱなしのタイプミス救済                                                                                                       |
| 全角スペース         | `Space`（leader）として扱う                                                                                                              |
| 配色                 | kanagawa-dragon。背景は透過せず既定より一段暗い `#121111` を使用                                                                         |
| ファイラ             | 隠しファイル・gitignore 済みも全部表示（`H` / `I` でトグル）。`<BS>` は開いたときのルートより上に行かない。cwd 基準の `Space E` は無効化 |
| ステータスライン     | 左端のモード表示を `NORMAL` の文字ではなく色付きの記号に（旧設定と同じ配色）                                                             |
| which-key            | `Space` を押したときのラベルを日本語表示（未登録の項目は英語のまま）                                                                     |
| `f` `t` `F` `T`      | hop.nvim の画面内ジャンプに置換（flash の f/t 拡張は無効化）                                                                             |
| 自動保存             | 編集停止 1 秒後に保存（auto-save.nvim / `:ASToggle` で一時停止・gitcommit は対象外）                                                     |
| LSP                  | go / rust / python / typescript / javascript / lua のサーバーを Mason に明示宣言                                                         |
| markdown             | lint は無効化（整形は prettier に任せる）                                                                                                |

有効にしている extras: claudecode / mini-surround / prettier / docker / git / go / json / markdown / python / rust / toml / typescript / yaml / treesitter-context

## 7. 差分を見る（hunk CLI）

差分の確認は Neovim ではなく **`hunk`**（Homebrew で入れた TUI diff ビューア）に任せています。
`~/.gitconfig` の設定はこれだけです。

```ini
[pager]
    diff = hunk pager
    show = hunk pager
```

| コマンド             | 動作                               |
| -------------------- | ---------------------------------- |
| `git diff`           | そのまま hunk が開く               |
| `git show`           | 同上                               |
| `hunk diff`          | git を介さず作業ツリーの差分を見る |
| `hunk diff --staged` | ステージ済みの差分                 |
| `hunk show HEAD~1`   | 特定コミットの差分                 |
| `hunk --help`        | サブコマンド一覧                   |

pager は端末に出力するときだけ使われるので、`git diff | grep ...` やスクリプト内では従来どおり素の
テキストが出ます。

Neovim 内で差分を見る手段としては、gitsigns（`]h` / `[h` で hunk 移動、`Space g h p` でプレビュー）と
`Space g g` の lazygit があります。

## 8. Claude Code 連携（claudecode.nvim）

Claude Code CLI を Neovim の中から使うための連携です。VS Code 拡張と同じ仕組みで、
Neovim が WebSocket サーバーを立て（`~/.claude/ide/<port>.lock` に接続情報を書く）、
そこに `claude` が繋がります。開いているファイルや選択範囲がそのまま Claude の文脈になります。

| キー        | 動作                                                                        |
| ----------- | --------------------------------------------------------------------------- |
| `Space a c` | Claude を開く / 閉じる                                                      |
| `Space a f` | Claude のウィンドウにフォーカス                                             |
| `Space a r` | 前回のセッションを再開（`--resume`）                                        |
| `Space a C` | 直前のセッションを継続（`--continue`）                                      |
| `Space a b` | 今のバッファを文脈に追加                                                    |
| `Space a s` | 選択範囲を Claude に送る（Visual モード）/ ファイラ上ではそのファイルを追加 |
| `Space a a` | Claude が出した差分を採用                                                   |
| `Space a d` | 差分を却下                                                                  |

主なコマンド: `:ClaudeCode`（トグル）、`:ClaudeCodeSelectModel`（モデル選択して起動）、
`:ClaudeCodeStatus`（接続状態）、`:ClaudeCodeStop`（サーバー停止）。

## 9. メンテナンス用コマンド

| コマンド                 | 用途                                                       |
| ------------------------ | ---------------------------------------------------------- |
| `:Lazy`                  | プラグイン管理画面（`U` で更新、`X` で削除、`q` で閉じる） |
| `:LazyExtras`            | 言語サポートや機能の追加・削除（`x` でトグル）             |
| `:Mason`                 | LSP・フォーマッタの管理（`i` でインストール）              |
| `:LspInfo` / `Space c l` | 今のファイルに効いている LSP を確認                        |
| `:checkhealth`           | 環境診断（依存ツールの不足を教えてくれる）                 |

extras を追加したら `lazyvim.json` が書き換わるので、そのまま git にコミットすれば別マシンでも再現できます。

## 10. 困ったとき

- **キー操作が分からない** → `Esc` 2 回 → `Space` を押して which-key を見る → `Space s k` で検索
- **プラグインが壊れた** → `:Lazy restore`（`lazy-lock.json` の状態に戻す）
- **完全にやり直したい** → `rm -rf ~/.local/share/nvim ~/.local/state/nvim ~/.cache/nvim` して `nvim` を起動（自動で再インストール）
- **prettier / vtsls が動かない** → `node --version` を確認。これらは node >= 18 が必要です。
  `.zshrc` は mise の後に nvm を読み込むので、nvm の default が古いバージョンだとそちらが優先されます
  （`nvm alias default 24` で設定済み）。`nvm use 12` したシェルから nvim を起動した場合も同じ症状になります。
- **旧環境のバックアップ** → 移行時の旧プラグイン群は `~/.local/share/nvim.bak-*` などに退避してあります。不要になったら削除して構いません。

## 11. 学習ロードマップ

1. **1 日目**: `vimtutor`（ターミナルで実行、30 分）で `hjkl` `i` `Esc` `dd` `u` を体に入れる
2. **2〜3 日目**: `Space Space`（ファイルを開く）と `Space /`（grep）だけで移動する練習
3. **1 週目**: `ciw` `ci(` `dd` `yy` `p` `.` を意識して使う
4. **2 週目**: `gd` `gr` `Space c r` `Space c a` で LSP を使いこなす
5. **それ以降**: `s`（flash ジャンプ）、`Space g g`（lazygit）、マクロ `qa` … と広げる

> 焦って全部覚える必要はありません。`Space` と `Space s k` の 2 つを知っていれば、必要なキーはその場で調べられます。
